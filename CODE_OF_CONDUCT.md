# Code of Conduct

VisualLLM is a collaborative project. Participants are expected to be
respectful, constructive, and professional.

Unacceptable behavior includes harassment, discrimination, personal attacks,
sexualized conduct, doxxing, deliberate disruption, and publishing someone
else's private information. Technical disagreement is welcome; hostility is
not.

Project maintainers may remove comments, close discussions, or restrict
participation when behavior violates these standards. Report concerns privately
through the security contact described in `SECURITY.md` until a dedicated
community contact is established.
